# issue-critic

問い・研究テーマ・企画・リサーチプランが「イシューからはじまっているか」を、
安宅和人『イシューからはじめよ』（英治出版、2010）の基準で点検し、
イシューではない箇所と、なぜイシューではないかを批判的に返す [Claude Code](https://claude.com/claude-code) スキル。

良い問いに書き直すスキルではありません。代案は出さず、穴の指摘に徹します。
直すのは書いた本人です。

## 何を見るか

- 問いになっているか（テーマ止まり、比較のない大きな問い）
- 出発点が正しいか（方法が先、似非イシュー、答えが出ても何も変わらない、仮説がない）
- 良いイシューの条件を満たすか（深い仮説、答えを出せるか、分解できるか）
- 情報との向き合い方（一次情報、集めすぎ）

点検項目の一覧は [references/criteria.md](references/criteria.md)。本の考え方の要約で、原文の引用ではありません。

## 返ってくるもの

```
判定：イシューになっていない ／ イシューになりかけ ／ イシューになっている
一番重い穴：…
指摘
1. ［基準］「本文の引用」
   なぜイシューではないか：…
   本人が答えるべき問い：…
指摘が見当たらなかった基準：…
```

例は [examples/example.md](examples/example.md)。

## 使い方

```bash
git clone https://github.com/Lazyturtle0852/issue-critic ~/.claude/skills/issue-critic
```

Claude Code で、研究案や企画書を貼るかファイルを指して「これイシューからはじまってる？」と聞く。
